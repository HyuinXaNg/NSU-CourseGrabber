# NSU-CourseGrabber
成都东软学院「体育项目」选课辅助工具，提供两种形态：桌面窗口版（Python + Tkinter，用 Playwright 驱动本机已装的 Chrome）与浏览器内 GUI 版（一段 JS 注入页面）。点「▶ 开始抢课」即运行，结束后用大字号明确显示是否抢到，以及没抢到的具体原因（已满员／找不到课程／服务器原文）。支持 13:00 这类准点开抢，通过 HTTP Date 响应头校准本机时钟偏差，实测落点误差约 10ms。全部靠文本特征定位课程卡片与按钮，不依赖任何 class 名，可抗教务系统改版。设计上刻意克制：每轮只抢一门、轮询带随机抖动、设有最长运行时长，避免高频请求影响全校共用的服务器。含 14 个测试文件、约 100 项断言。
